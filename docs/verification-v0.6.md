# v0.6 / Commit 26~32 검증

## 구현

계정은 릴레이별 선택 기능이며 기존 토큰 인증을 유지한다. 기기 등록 코드의 만료·단일 사용, 계정 소유자의 기기 폐기, 멤버십·키 갱신과 재시작 후 폐기 상태를 검증한다. 계정 생성이 네트워크 권한을 부여하지 않는다.

Directory는 HTTPS 인증서와 별도 Ed25519 서명을 검증한다. 만료·미래 시각·변조·잘못된 키를 거부하고 수동 서버를 유지한다. 로컬 HTTPS 서버로 정상 응답·인증서 거부·변조 거부를 검증한다. 공식 서비스는 배포하지 않았다.

비밀번호는 scrypt로 저장하며 관리자 승인과 함께 사용할 수 있다. 평문 저장 없이 잘못된 비밀번호, 일반 가입 요청 우회, 시도 횟수 제한과 보호 상태의 원자적 생성 경로를 검증한다. 실제 QUIC 연결에서도 계정·등록·비밀번호 요청을 검증한다.

초대는 네트워크에 바인딩한 160비트 임의 코드다. 만료·사용 횟수·회수와 관리자 역할 비부여를 검증한다. 링크/코드는 연결된 릴레이에 붙여 넣어 사용하며 운영체제 URL 핸들러는 등록하지 않는다.

UI는 첫 실행의 언어 선택·연결 확인·생성/참여 안내, 한국어/영어 표시와 사용자별 설정 보존을 제공한다. 번역문 전체의 printf 형식 토큰 일치를 검사하며 Windows CI에서 영어·한국어·한국어 첫 실행 화면을 각각 캡처한다. 멤버/경로는 실제 서비스 상태를 사용하며 끊긴 연결과 오래된 상태는 온라인으로 표시하지 않는다.

## 검증 환경과 제한

Linux의 전체 실행 파일과 공통 테스트, 로컬 인증 TLS/QUIC 통합 검사를 실행한다. Windows 설치·업그레이드 복구·EXE·실제 서비스/Wintun·UI 화면과 macOS 공통 모듈은 GitHub Actions의 동일 최종 커밋 결과로 확인한다. 정확한 성공 여부는 해당 커밋의 Actions 결과를 따른다.

운영 서버나 실제 사용자의 설정·토큰은 변경하지 않았다. 자체 서버·토큰을 이미 설정한 Windows 사용자의 연결 이후 흐름을 기준으로 한다. 인터넷 NAT/실제 친구 기기의 사용자 동선, 공식 Directory 운영과 다중 OS 클라이언트 설치는 이번에 실측하지 않았다. 등록된 인증 토큰이 없는 완전한 무설정 가입을 주장하지 않는다. 상세한 제한은 각 기능 문서에 정리한다.

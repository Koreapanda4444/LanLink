# LanLink 0.2.1

Windows 설치 실패 복구를 수정했다. 업그레이드 중 설정 파일이나 인증 토큰 파일이 다른 프로그램에 의해 잠겨 있으면, 바뀌지 않은 파일을 불필요하게 다시 쓰지 않고 기존 프로그램·설정·토큰·폴더 권한을 복원한다. 각 복구 단계를 독립적으로 실행해 한 단계의 오류 때문에 나머지 복구가 누락되지 않도록 했다.

실행 중이던 서비스는 복구가 모두 끝난 뒤 다시 시작한다. 복구가 불완전하면 서비스를 다시 시작하지 않고 오류와 보관된 백업 위치를 알린다.

기존 0.2.0 배포본으로 파일 잠금 문제를 재현하고, 수정본 ZIP·EXE 설치와 실행 중인 서비스의 QUIC·TLS 연결 복구를 검증한다. 기존 0.2 설정과 기기 인증 정보를 유지하며, Windows EXE·ZIP 및 일반 Linux x64 릴레이 패키지를 제공한다.

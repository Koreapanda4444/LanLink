# LanLink 0.3.0 개발 마일스톤

가상 IPv4 패킷 엔진, 어댑터와 Relay 세션을 분리하고 경로 공통 인터페이스를 추가했다. 기존 Windows Wintun·서비스·Named Pipe와 Linux Relay를 유지한다.

프레임 버전 5를 유지하는 선택적 기능 협상을 추가했다. v0.2.2 Relay에 새 클라이언트를 연결하는 QUIC·TLS/TCP 호환 검사와, 협상하지 않는 클라이언트의 새 Relay 접속 검사를 포함한다.

버전이 있는 경로 진단, 패킷·손실 통계, 고정된 오류 코드를 추가했다. 제공되지 않는 재전송 수치는 임의의 0으로 표시하지 않는다. Windows/Linux 전체 검사와 별도로 macOS에서 공통 모듈을 빌드·시험하는 진입점을 마련했다. macOS 클라이언트·utun·패키지 지원은 후속 단계다.

이 버전은 개발 마일스톤이며 공개 Release 발행은 별도 승인 후 진행한다.

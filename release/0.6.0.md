# LanLink 0.6.0 development milestone

- Optional relay-local accounts, single-use device enrollment and persistent revocation.
- Authenticated HTTPS directory bootstrap with independently pinned Ed25519 catalogs and manual relay fallback.
- Password-protected joining with scrypt, bounded attempts and optional owner approval.
- Expiring, bounded-use invitation links and clipboard codes, with owner revocation.
- Simplified desktop creation/joining, member presence, path overview and clipboard diagnostics.
- First-run guidance and Korean/English desktop localization, independent of installer language.

Existing relay-token authentication remains supported and accounts are optional. SQLite schema upgrades to version 6; back up the database before upgrading, because older binaries cannot open it. Directory discovery requires a configured trusted HTTPS endpoint; no official directory is deployed by this milestone. Cross-platform client packaging and later topology work remain on the v1 roadmap. Public publication requires separate approval.

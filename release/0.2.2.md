# LanLink 0.2.2

서로 연결된 L 두 개를 형상화한 LanLink 로고를 적용했다. Windows 앱·서비스·명령줄 도구와 릴레이 실행 파일에 다중 해상도 아이콘과 버전 정보를 포함하며, 데스크톱 앱 상단에도 로고를 표시한다.

Windows EXE 설치 프로그램에 전용 로고와 시작·완료 화면을 추가했다. 릴레이, 인증 파일, 프로그램·데이터 위치를 설치 전에 요약해서 확인할 수 있고, 서비스 설정 중에는 진행 표시와 안내를 보여준다.

설치 시작 시 한국어·영어를 선택할 수 있다. 기본 마법사, 연결 설정, 오류 안내와 완료 화면에 선택한 언어를 적용하고, 무인 설치에서도 `/LANG=ko`·`/LANG=en`을 지원한다. 데스크톱 앱 UI는 영어로 제공한다.

기존 0.2 설정·장치 ID·인증 정보와 설치 실패 복구 방식을 유지한다. Windows EXE·ZIP과 Linux x64 릴레이 패키지를 제공한다.

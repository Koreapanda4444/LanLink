# LanLink 0.1.0

Windows x64 clients and an Oracle Linux 9 x64 relay can form private IPv4 networks with owner-approved membership. Clients use QUIC UDP, fall back to authenticated TLS 1.3 over TCP, and reconnect with their persisted device identities and virtual addresses. Virtual packets are encrypted between clients; the relay forwards ciphertext. Broadcast and IPv4 multicast stay inside the selected network.

The Windows package includes the desktop UI, service, command-line client, Wintun 0.14.1, runtime libraries, dependency licenses, and administrator install/uninstall scripts. The relay package includes its runtime libraries, systemd unit, dependency licenses, and transactional install/upgrade/uninstall scripts. Existing configuration and persistent state are preserved on upgrade and ordinary uninstall.

Relay connections, concurrent TLS handshakes, queued send bytes/frames, and control request rates have configurable limits. Data packets are dropped under backpressure while control messages retain reserved queue capacity. A peer that cannot accept control updates is disconnected so it can restore current state on reconnect.

CI checks Windows installation, upgrade, firewall and uninstall behavior, native Oracle Linux relay packaging, and real relay-process scenarios with three clients. The latter cover QUIC and TCP fallback, packet encryption/decryption, unicast, large packets, broadcast/multicast isolation, replay rejection, relay restart, lease recovery, eviction, and connection capacity recovery. Slow-reader tests verify that one blocked TCP client does not stall another.

Download both the package for your platform and `SHA256SUMS`. `release-manifest.json` records the exact source commit, package hashes and build metadata. Follow the included `INSTALL.md` for installation and upgrades.

This first release supports Windows x64 clients and Oracle Linux 9 x64 relays, IPv4, and protocol version 5. LanLink executables and installer scripts are unsigned; the bundled official Wintun driver is signed. Certificates and shared authentication tokens are supplied by the operator. IPv6 tunneling, public cloud provisioning, and live Windows-to-Oracle host testing are outside this release's automated validation.

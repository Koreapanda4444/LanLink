# LanLink 0.2.0

Windows 데스크톱에서 네트워크와 기기를 관리하는 화면을 정리했다. 선택한 네트워크의 가상 IP, 실제 기기 목록과 접속 상태를 확인하고 IP·네트워크 ID·기기 ID를 복사할 수 있다. 현재 서비스가 받은 가입 요청은 목록에서 승인하며, 탈퇴와 기기 제거는 확인 후 적용한다. 연결 방식, 지연 시간과 송수신 상태도 표시한다.

`LanLink-Setup-0.2.0-windows-x64.exe`는 릴레이 주소와 토큰 파일을 입력받는 설치 프로그램이다. 서비스, UI, Wintun과 필요한 DLL을 함께 설치한다. 기존 설정과 기기 인증 정보는 업그레이드 시 유지하고, 설치 실패 시 이전 설치를 복구한다. ZIP 패키지도 제공한다.

릴레이 배포를 Oracle Linux 전용 경로에서 일반 Linux 서버용으로 변경했다. `LanLink-relay-0.2.0-linux-x86_64.tar.gz`는 glibc 2.34 이상인 Linux x64 서버용이다. 같은 패키지를 Oracle Linux 9, Ubuntu 22.04, Debian 12에서 설치·실행·업그레이드·복구·제거 검증한다. 클라우드 제공자와 관계없이 사용할 수 있다. 설치기는 systemd를 사용하고, 실행 중인 firewalld가 있으면 해당 포트를 설정한다. UFW 등 다른 방화벽과 클라우드 보안 규칙은 관리자가 별도로 설정한다.

Windows CI는 실제 SCM 서비스와 Wintun 어댑터 두 개를 사용해 TCP·UDP 왕복, QUIC·TLS 전환, 네트워크 격리, 서비스·릴레이 재시작, 실행 중 업그레이드 실패 복구를 검증한다. 설치 EXE의 설치·업그레이드·실패 처리와 실제 UI 렌더링도 확인한다. 서로 다른 인터넷의 PC 두 대와 외부 서버 연결, 절전 복귀·재부팅 검증은 별도로 수행해야 한다.

`SHA256SUMS`와 `release-manifest.json`에 파일별 해시와 소스 커밋을 기록한다. LanLink 실행 파일과 설치 프로그램은 서명되지 않았으며, 포함된 공식 Wintun 드라이버는 서명된 배포본이다. IPv4와 프로토콜 버전 5를 사용한다.

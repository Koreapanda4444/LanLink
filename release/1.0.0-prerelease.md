# LanLink 1.0.0 프리릴리스

Windows x64 설치 EXE·ZIP, Linux x64 Relay·데스크톱 클라이언트, macOS arm64 클라이언트를 공개한다. 전체 CI 8개와 배포 패키지 5개 검증을 통과한 소스 `4f819c66786ee9d59593e793819dd228c78814ae`의 패키지다.

## 주요 변경

- 장치 인증과 종단 간 암호화를 유지하는 Direct QUIC, Relay QUIC 및 TLS/TCP fallback.
- IPv4 LAN 검색·fanout·게임 진단, Mesh·Hub·ACL·Windows Gateway, 선택 Linux L2.
- 한국어·영어 UI, 선택 계정·Directory·비밀번호·초대와 자체 호스팅.
- 다중 리전 Relay·장애 복구·공유 quota, 설정 생성·설치·WAL 백업·복원.
- TLS 동시 종료·재시작 보완, 패킷 인증 헤더의 불필요한 복사 제거.
- MsQuic 2.6.3·OpenSSL 3.6.4 고정과 오래된 런타임 거부.

## 다운로드

| 파일 | 용도 |
|---|---|
| `LanLink-Setup-1.0.0-windows-x64.exe` | Windows 설치 프로그램 |
| `LanLink-1.0.0-windows-x64.zip` | Windows 수동 설치 |
| `LanLink-relay-1.0.0-linux-x86_64.tar.gz` | Linux x64 Relay 서버, glibc 2.34 이상 |
| `LanLink-1.0.0-linux-x64.tar.gz` | Ubuntu 24.04 x64 데스크톱 클라이언트 |
| `LanLink-1.0.0-macos-arm64.zip` | macOS 14 이상 Apple Silicon 클라이언트 |

받은 파일은 `SHA256SUMS`로 확인한다. `INSTALL.md`에 설치·업그레이드 절차가 있으며 `release-manifest.json`에 소스 SHA와 파일별 해시가 들어 있다. 업그레이드는 전체 패키지로 수행하고 기존 설정·identity·토큰·DB는 보존한다. 자체 서버에는 Relay 주소와 인증 토큰 설정이 필요하다.

## 검증 범위와 알려진 제한

Windows·Linux·macOS native 회귀, 실제 OS 서비스·커널 어댑터·설치·업그레이드·롤백·제거를 검사했다. Linux 커널의 두 NAT 라우터에서 암호화 Direct 통신과 UDP 차단 뒤 인증된 TLS fallback도 확인했다. 동일 Relay archive를 Oracle Linux 9·Ubuntu 22.04·Debian 12에서 검사했다.

**실제 공유기/공인 NAT·혼합 OS 사이 실시간 가상 IP 왕복·물리 host/guest 게임 플레이는 미검증이다.** 이 때문에 정식 안정판 대신 프리릴리스로 공개한다. 세 OS의 암호화 상호운용은 artifact 교환 방식이며 실시간 OS 간 전송 시험을 대신하지 않는다.

macOS 앱은 ad hoc 서명이며 Developer ID·Apple 공증·Intel Mac 및 최소 버전 실기기 실행은 미확인이다. Windows 실행 파일과 설치 프로그램 자체는 서명되지 않았고 포함된 공식 Wintun 드라이버는 서명된 배포본이다. Unix Gateway LAN 전달과 다른 OS의 L2는 지원하지 않는다. 지역 상행은 TLS/TCP이며 중앙의 active-active HA를 제공하지 않는다. 공식 Directory/Relay 운영 인프라는 이 릴리스로 자동 생성되지 않는다.

# LanLink 1.0.0-preview.6

설치 화면과 데스크톱 디자인을 개편한 프리릴리스다. 앱 내부 버전과 패키지 파일명은 1.0.0이며, 개편 전 v1.0.0과 구분하기 위해 새 태그로 배포한다.

- 설치기 왼쪽의 LanLink 로고와 남색 사이드바를 복원했다. 설명은 가상 LAN과 LAN 멀티플레이 용도를 안내하도록 수정했다.
- 앱은 검정·남색 바탕, 파란 버튼과 선택 영역, 밝은 글자로 변경했다. 서버 연결 영역에 원래 LanLink 아이콘을 표시한다.
- 기본 창은 500×750이다. 메뉴·서버 선택·연결 상태·네트워크·멤버 목록 구성을 유지한다.
- Windows에서 모니터별 DPI를 적용하고 글꼴을 해당 해상도로 다시 그린다. Linux/macOS에서도 고밀도 화면에 맞는 글꼴 아틀라스를 사용한다.
- 작업량에 따라 0~100%까지 차오르는 설치 진행률은 유지했다.
- Windows 설치 중 서버 주소·포트·토큰 입력을 제거했다. 같은 Setup EXE에서 Install·Modify·Repair·Uninstall을 제공한다.
- Windows·Linux·macOS에서 서버가 없어도 앱과 서비스가 실행된다. 서버 등록과 연결은 앱에서 진행한다.
- 여러 서버 프로필을 저장하고 전환하며, 서버별 기기 identity·인증 정보·신뢰 지문을 분리한다.
- 운영자의 공용 관리 비밀을 공유하지 않고 일회용 코드로 기기를 등록한다. 운영자는 기기별 접근을 철회할 수 있다.
- lanlink:// 초대에서 서버와 네트워크를 확인하고 승인한 후 연결한다. 네트워크 가입 응답이 끊기면 가입 여부를 확인하며 최대 3회 재시도한다.
- Linux 클라이언트와 Relay를 같은 호스트에 설치할 수 있다. 기존 가상 IPv4·암호화·P2P·Relay 기능을 유지한다.

## 다운로드

| 파일 | 용도 |
|---|---|
| LanLink-Setup-1.0.0-windows-x64.exe | Windows x64 설치 프로그램 |
| LanLink-1.0.0-windows-x64.zip | Windows x64 수동 설치 패키지 |
| LanLink-1.0.0-linux-x64.tar.gz | Ubuntu 24.04 x64 데스크톱 클라이언트 |
| LanLink-1.0.0-macos-arm64.zip | macOS 14 이상 Apple Silicon 클라이언트 |
| LanLink-relay-1.0.0-linux-x86_64.tar.gz | Linux x64 Relay 서버, glibc 2.34 이상 |

Windows 사용자는 EXE를 내려받아 설치한다. 설치 후 앱에서 서버를 등록하거나 초대 링크를 연다. 자체 서버가 필요하며 공식 공용 서버는 운영하지 않는다. 운영자 빠른 설정은 각 패키지의 SERVER-SETUP.md를 참고한다. Repair와 일반 재설치는 사용자 데이터를 보존하며, 제거 시 데이터 삭제를 별도로 선택한다.

SHA256SUMS와 release-manifest.json에 파일 해시·크기·소스 SHA를 포함했다. 기존 v1.0.0 태그와 배포 파일은 보존한다.

## 검증 범위와 제한

이번 릴리즈는 화면·설명·DPI 렌더링 변경이다. 사용자 요청에 따라 실행 테스트를 생략하고 플랫폼별 빌드와 패키지 생성만 수행했다. 배포 파일의 소스 정보·파일 구성·체크섬 확인은 유지한다. UI·설명만 바뀐 push는 Windows 설치 실행 확인과 Relay 실행 확인을 생략하며, 설치 백엔드·서비스·통신 코드가 바뀌면 기존 실행 확인을 수행한다.
물리 공유기 NAT·혼합 OS 실시간 통신·장시간 실제 게임 플레이는 별도 실사용 검증으로 남아 있다. Windows 설치 프로그램과 실행 파일은 코드 서명되지 않았으며, 포함된 공식 Wintun 드라이버는 서명된 배포본이다. macOS 앱은 ad hoc 서명이며 Apple 공증은 제공하지 않는다. SPKI 지문으로 고정한 Relay 연결은 검증된 TLS 1.3/TCP를 사용한다.

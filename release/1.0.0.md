# LanLink 1.0.0 — 릴리스 준비

Windows x64 ZIP/EXE, Linux x64 Relay·데스크톱 client, macOS arm64 client의 다섯 패키지를 준비한다. 공개 안정판 발행은 자동으로 수행하지 않는다.

- 서명된 P2P 후보·UDP 탐색·Direct QUIC·기존 Relay QUIC/TLS fallback과 종단 간 암호화.
- IPv4 fanout·LAN 검색·게임 진단·선택 Linux L2·Mesh/Hub/ACL·Windows Gateway.
- 선택 계정·공식/자체 Directory·비밀번호·초대·한국어/영어 UI.
- 하나의 영구 authority를 공유하는 지역 Relay와 장애 복구·공유 quota·inventory 배포·WAL snapshot/복원.
- TLS 수신기 동시 시작·종료 정리, 인증 헤더의 payload 복사 제거와 재현 가능한 비교 지표.
- MsQuic 2.6.3/OpenSSL 3.6.4 고정, 오래된 런타임 거부, Unix 높은 fd 경계 수정과 보안 정책 provenance 검사.
- 격리된 Linux kernel NAT 두 개에서 Direct 암호화 연결과 UDP 차단 후 TLS 제어 fallback을 검사하는 CI 경로.

기존 설정·장치 identity·토큰·DB를 보존하는 설치·업그레이드·실패 롤백·제거 시험과 v0.2.2 Relay 호환 검사를 유지한다. wire protocol 5와 `lanlink/5` ALPN은 유지한다. 업그레이드 시 프로그램 일부 파일만 교체하지 말고 전체 패키지를 사용한다. Relay 버전 롤백은 해당 버전의 상태 백업과 패키지를 함께 사용한다.

## 승인 전에 남은 검증

실제 공유기/공인 NAT·혼합 OS의 실시간 가상 IP 통신·물리 host/guest 게임 플레이는 완료되지 않았다. 자동 시험과 물리 시험을 구분한 `docs/compatibility-matrix.md`와 `docs/verification-v1.0.md`를 참고한다. `release/readiness.json`의 필수 수동 시험이 증거와 함께 통과하기 전에는 공개 발행 도구가 실패한다. 이를 충족한 뒤에도 공개 Release는 별도 승인 후 실행한다.

macOS 앱은 ad hoc 서명이며 Developer ID·Apple 공증·Intel Mac·최소 버전 장비에서의 실제 실행은 미확인이다. Unix Gateway LAN 전달과 다른 OS의 L2는 지원하지 않는다. 지역 상행은 TLS/TCP이며 중앙의 active-active HA는 제공하지 않는다. 공식 유료 인프라·DNS 변경은 이 작업에 포함하지 않는다.

# LanLink 0.5.0 개발 마일스톤

- 기존 Direct QUIC·Relay 폴백 위에서 가상 서브넷 broadcast와 범위가 제한된 multicast 전달을 보강했다.
- 검색 트래픽의 속도 제한, 중복·반사·재생 방지와 IPv4 MTU·조각 처리를 추가했다.
- Teeworlds 0.7.5 전용 서버 검색 프로토콜을 고정된 원본 버전과 실제 서버 질의로 검사한다.
- 데스크톱 게임 진단과 CLI `game`에서 가상 MTU·피어 수·검색 전달량·차단 수치를 제공한다. 직접 IP 접속, 게임 버전과 방화벽 확인 방법을 함께 표시한다.
- Linux 소스 빌드에 선택적 `lanlink-l2` 실행 파일을 추가했다. 실제 TAP의 ARP/IPv4 Ethernet 프레임을 기존 E2E 암호화 경로로 전달한다. 일반 Wintun 모드와 별도 네트워크에서 사용하며 Windows/macOS L2, IPv6, 물리 LAN 브리지는 지원하지 않는다.

v0.2.2 설정과 Relay 프로토콜, Windows 설치 EXE·한국어/영어 설치 과정은 유지한다. 자세한 검증 범위는 `docs/verification-v0.5.md`, 게임별 근거는 `docs/game-compatibility.md`, Linux Ethernet 실행 방법은 `docs/l2.md`에 있다. 일반 push는 개발 아티팩트를 생성하며 공개 Release는 별도로 발행한다.

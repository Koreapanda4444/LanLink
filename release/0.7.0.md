# LanLink 0.7.0 development milestone

- Optional managed mesh and hub-and-spoke restrictions across Relay and direct QUIC.
- Default-deny device/group ACLs, owner-assigned administrator/member/restricted roles.
- Two-step gateway registration and private subnet advertisements with overlap checks.
- Explicit local routing opt-ins, encrypted routed IPv4, Windows route cleanup and scoped WFP forwarding.
- Bounded administrative audit history and Korean/English management previews.

Existing unmanaged networks and relay-token accounts preserve their behavior. SQLite upgrades to schema 8; back up the database before upgrading. Managed networks require compatible clients and an online owner to rotate keys. Gateway LAN forwarding and return routes require local administrator setup; DNS, Internet default routes, NAT and physical forwarding flags are never changed by LanLink.

Windows client and Linux relay packages are prepared by CI. Linux/macOS full L3 client installation and real NAT/physical LAN deployments remain outside this milestone. Public Release publication requires separate approval.

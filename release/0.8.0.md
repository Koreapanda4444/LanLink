# LanLink 0.8.0

- Windows Wintun/Win32/DirectX 실행부를 보존하며 공통 서비스·UI 모델을 분리했다.
- Linux TUN 및 macOS utun에 IPv4 주소·MTU·경로 관리와 정리를 추가했다.
- systemd·launchd 서비스, 권한이 제한된 Unix 로컬 제어 채널과 데스크톱 CLI를 제공한다.
- SDL3/OpenGL 한국어·영어 UI, Linux x64 패키지와 macOS 네이티브 앱 패키지·아이콘을 추가했다.
- 설정·장치 ID·토큰을 보존하는 업그레이드와 복구, 기본 상태 보존 제거 및 명시적 purge를 지원한다.
- macOS 배포용 Developer ID 서명·공증 절차는 운영자의 자격정보가 있을 때 별도로 실행한다.

검증 결과와 미확인 항목은 `docs/verification-v0.8.md`에 기록한다. 공개 Release 발행은 별도 승인 후 진행한다.

# LanLink 0.4.0 개발 마일스톤

- 인증된 네트워크 멤버 사이의 후보 교환, NIC 후보 수집, 선택적 자체 STUN, 서명된 UDP 탐색과 Direct QUIC.
- 현재 멤버 자격·키·세션에 묶인 직접 세션과 기존 패킷 E2E 암호화/재생 방어 유지.
- Direct 실패 시 기존 Relay QUIC/TLS-TCP 전달, 품질 기반 선택 및 NIC 변경 후 재탐색.
- 데스크톱 피어 목록에 Direct/Relay 경로, RTT 및 폴백 사유 표시. CLI `paths`에서 동일한 진단 제공.
- Windows 설치 EXE·한국어/영어 설치 과정·로고·Wintun 서비스 및 Linux Relay 패키지 보존.

v0.2.2의 설정과 Relay 프로토콜을 유지한다. 새 기능을 협상하지 못한 Relay/피어는 기존 경로를 사용한다. 공개 Release 발행은 수동 승인 단계로 유지하며 일반 push는 CI 아티팩트를 생성한다.

실물 공유기 NAT, 물리 NIC 전환, 실제 게임 및 macOS 클라이언트는 이 마일스톤에서 검증했다고 표시하지 않는다. 현재 자동 시험 범위는 `docs/verification-v0.4.md`를 참고한다.

# LanLink 0.9.0

- 지역·용량·프로토콜·authority·상태 서명 키를 포함한 LLD2 서버 목록을 추가했다.
- 상태 서명·TLS·nonce를 확인한 실측 RTT/부하 기반 Relay 선택, 유지 시간·개선 임계값과 수동 고정을 지원한다.
- 하나의 영구 authority를 공유하는 QUIC/TLS 지역 앞단과 장애 후 재인증·네트워크·키·가상 IP 복원을 추가했다.
- 장치·네트워크·중앙 전체의 바이트/전달 수 제한, 재접속 후에도 유지되는 요청 제한과 공개 aggregate 집계를 추가했다.
- 실제 노드 키를 대조하는 설치, inventory 기반 설정/서명 catalog 생성, SQLite snapshot 백업과 차단된 빈 대상에 대한 복원 도구를 포함한다.
- 기존 Windows/Linux/macOS 클라이언트와 0.2.2 Relay 호환·설치·롤백 검사를 유지한다.

운영 절차는 `self-hosting/README.md`, source의 `docs/self-hosting.md`를 참고한다. 중앙의 active-active HA를 제공하지 않으며 지역 상행 데이터는 TLS/TCP이다. 실제 공인 다중 리전·물리 NAT 시험과 macOS Developer ID·공증은 완료 범위가 아니다. 공개 Release 발행은 별도 승인 후 진행한다.
